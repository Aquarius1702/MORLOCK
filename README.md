# MORLOCK

## Status

Definiranje proizvoda i priprema za razvoj — implementacija još nije započela.

MORLOCK se razvija na više računala. Trajne informacije potrebne za nastavak rada nalaze se u ovom repozitoriju, a ne samo u pojedinom Codex chatu.

## Svrha

Morlock je SaaS aplikacija za upravljanje neposrednim, vremenski ograničenim najmom rekvizita. Nije booking sustav niti sustav za online naplatu; zaposleniku treba omogućiti brz početak najma, praćenje vremena i potvrdu završetka najma.

Potpuni poslovni i funkcionalni zahtjevi nalaze se u projektnoj specifikaciji.

## Pokretanje

Backend je predviđen za postojeći web hosting s PHP-om i MySQL/MariaDB bazom. Upute za instalaciju, konfiguraciju i pokretanje bit će dodane nakon što se potvrde minimalna arhitektura i verzija PHP-a.
